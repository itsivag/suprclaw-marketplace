# Ops Agent Skill Source

The skills under `marketplace/ops/skills` are first-party SuprClaw marketplace skills.

They are source-informed by public operations and knowledge-work patterns, including:

- Asana guidance on meeting notes, decisions, action items, owners, and due dates
- Zapier daily command-center patterns for inbox, calendar, goal, and follow-up briefings
- Atlassian operational planning guidance for priorities, review cadence, goals, risks, and execution plans
- Public meeting-notes agent-skill examples for structured summaries and follow-through

No third-party skill code is vendored in this directory.
