# Docs Notes Organizer

Turn scattered information into a clean operational document.

## Organization Framework

Use this structure unless the user asks for another format:

```markdown
# [Document Title]

## One-Line Summary
- ...

## Context
- ...

## Key Points
- ...

## Decisions
| Decision | Rationale | Owner | Follow-up |
|---|---|---|---|

## Action Items
| Priority | Action | Owner | Due | Status |
|---|---|---|---|---|

## Open Questions
| Question | Owner | Needed by |
|---|---|---|

## References / Source Notes
- ...
```

## Rules

- Preserve important source meaning while reducing clutter.
- Do not remove uncertainty; label it.
- Use headings that make the doc easy to search later.
- If the content mixes multiple topics, split by workstream.
