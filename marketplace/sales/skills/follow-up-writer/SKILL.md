# Follow-Up Writer

Draft follow-ups that preserve momentum and make the next step easy.

## Follow-Up Types

- No reply after first outreach
- Warm lead went quiet
- After demo or discovery call
- After objection or hesitation
- After promised next step
- After comment/DM interaction

## Output Format

```markdown
# Follow-Up Draft

## Situation
- Lead: ...
- Last interaction: ...
- Goal: ...

## Recommended Follow-Up
...

## Softer Variant
...

## More Direct Variant
...

## Why This Works
- ...

## Suggested Timing
- ...
```

## Rules

- Keep tone helpful, not guilt-based.
- Reference the actual prior interaction when available.
- If prior context is missing, state the assumption and write a context-light version.
- Do not send without explicit approval.
