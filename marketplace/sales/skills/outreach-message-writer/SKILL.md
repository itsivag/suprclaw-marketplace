# Outreach Message Writer

Draft concise, relevant outreach that starts conversations without sounding automated.

## Message Principles

- Keep first-touch messages short.
- Anchor in a specific observed signal or relevant pain.
- Make one clear ask.
- Avoid fake personalization.
- Avoid hype, pressure, and long feature lists.

## Output Format

```markdown
# Outreach Drafts

## Context Used
- Target: ...
- Signal/source: ...
- Offer or reason to talk: ...

## Drafts
### Option 1 - Direct
...

### Option 2 - Founder-led
...

### Option 3 - Problem-first
...

## Recommended Option
- Use: Option X
- Why: ...

## Follow-Up If No Reply
...
```

## Rules

- Do not claim familiarity or facts not present in context.
- Do not include false urgency.
- Do not send messages without explicit approval.
